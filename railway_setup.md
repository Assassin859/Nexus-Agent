# Railway Deployment Guide — Remote Ollama Dev Server

Follow these instructions to deploy a private, high-performance `qwen2.5:7b` model on Railway. This will serve as your remote AI brain during local development, saving your machine's CPU/GPU and RAM resources.

---

## 1. Railway Deployment Settings

Log into your secondary Railway account and create a new project with the following settings:

| Setting | Value |
|---|---|
| **Source** | Deploy from Docker Image |
| **Docker Image** | `ollama/ollama:latest` |
| **Expose Port** | `11434` (Railway will automatically map this) |
| **Persistent Volume** | Mount `/root/.ollama` (Size: 10GB - 20GB is recommended to store model weights) |
| **Public Networking** | Enable Public Domain in settings (e.g., `https://ollama-production-xxxx.up.railway.app`) |

---

## 2. Initialize the Model (Pulling qwen2.5:7b)

Once the service status on Railway turns to **Active/Running**, the Ollama server is live but has no models downloaded yet. 

To download the model onto the Railway server, execute this curl command from your local terminal. Replace `https://your-ollama-url.up.railway.app` with the actual public domain generated by Railway:

```bash
curl -X POST https://your-ollama-url.up.railway.app/api/pull \
  -H "Content-Type: application/json" \
  -d '{"name": "qwen2.5:7b"}'
```

*Note: This command will return immediately with a streaming download status. The download happens directly between Railway's servers and Ollama's registry, taking roughly 1–2 minutes.*

### Verify Download
To confirm the model is successfully downloaded and ready for use on Railway, run:
```bash
curl https://your-ollama-url.up.railway.app/api/tags
```
**Expected Response:**
```json
{
  "models": [
    {
      "name": "qwen2.5:7b",
      "model": "qwen2.5:7b",
      "details": { ... }
    }
  ]
}
```

---

## 3. Local Development Connection (.env.local)

Once verified, configure your local environment inside your development workspace by setting these environment variables. This redirects the Vercel AI SDK to your remote Railway instance:

```env
# Point to your remote Railway deployment
OLLAMA_URL=https://your-ollama-url.up.railway.app/api

# Target the higher parameter model
OLLAMA_MODEL=qwen2.5:7b
```

---

## 4. Test Script (Verify Brain Connection)

To test the remote brain from your machine before the build phase starts, you can run this test script in your terminal:

```bash
curl -X POST https://your-ollama-url.up.railway.app/api/generate \
  -H "Content-Type: application/json" \
  -d '{"model": "qwen2.5:7b", "prompt": "Identify the primary action in JSON: Repay 500 USDC on Aave because health factor is 1.12.", "stream": false}'
```

**Expected JSON Response:**
```json
{
  "model": "qwen2.5:7b",
  "response": "{\n  \"action\": \"repay\",\n  \"amount\": 500,\n  \"token\": \"USDC\",\n  \"protocol\": \"Aave\",\n  \"reason\": \"Health factor is 1.12\"\n}",
  "done": true
}
```
